Sign-in · Azure AD app registration

By default the app signs you in using Microsoft’s pre-authed “Microsoft Azure CLI” public client — zero setup, but it’s only allowed to ask for Directory.AccessAsUser.All. For cloud-syncing the mapping files to OneDrive / a Teams SharePoint site, we need Files.ReadWrite and Sites.ReadWrite.All, which Microsoft hasn’t pre-authorised on that client. Register your own Azure AD app once and paste the Client ID below to unlock it.

One-time setup — create the app registration
  1. Open the Entra admin centre → App registrations and click New registration.
  2. Name it KFC Entra User Manager. Supported account types → Accounts in this organisational directory only. Leave the redirect URI blank.
  3. Open Authentication → under Advanced settings set Allow public client flows to Yes, then Save.
  4. Open API permissions → Add a permission → Microsoft Graph → Delegated permissions → tick:
    • Directory.AccessAsUser.All
    • Files.ReadWrite
    • Sites.ReadWrite.All
    Click Add permissions. (Admin consent isn’t required for these — you’ll see one consent prompt at next sign-in.)
  5. Copy the Application (client) ID from the overview page and paste it below.
