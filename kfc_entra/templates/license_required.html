How licensing works

Each license is tied to one computer. The first time you save a key, the app sends a non-PII fingerprint of this machine (a hash of the MAC address + hostname) to the license server, which binds the key to that fingerprint. From then on, the app re-verifies the key on every launch — if it’s ever revoked or expired, the lock takes effect the next time you start the app.

Replacing this computer? Email support with your license key and we’ll release the binding so you can reactivate on the new machine.
